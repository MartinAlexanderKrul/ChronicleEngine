# Gatefall Profile 1.33 — Stat Passives and Flux Sight Implementation Plan

**Status:** complete — adopted as `EVT-000188`; checklist retained as the execution record.

**Goal:** Complete Phase 3 of the approved Flux Sight design by replacing the two-threshold
stat-milestone model with five Rank-derived Stat Passives, renaming Rank-Sight to Flux Sight,
and migrating the live campaign without reopening play.

**Authority:** `docs/superpowers/specs/2026-07-29-flux-sight-and-passive-unification-design.md`
§4, §8, and §9 (Phase 3).

## Constraints

- Profile **1.32 → 1.33**; Engine 0.2.0 and Data Model 0.1.5 unchanged.
- Adoption Event **EVT-000188**; no new `REC-`.
- Stat thresholds: **30 / 36 / 44 / 54 / 66 / 80 → E / D / C / B / A / S**.
- Rank is derived from the governing **base Stat**, clamped at System Rank + 1.
- No mastery track, stars, qualifying scenes, mastery progress, Rank ascension, or
  `scope_floor` for Stat Passives.
- Existing successful-application counts carry forward as `successful_uses`.
- No resolved roll, fictional time, pool, Stat, item, transaction, or checkpoint changes.
- Nothing under `saves/` and no engine decision file may change.
