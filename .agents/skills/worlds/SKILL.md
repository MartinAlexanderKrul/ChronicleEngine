# /worlds — List Available Worlds

Thin dispatcher only — this skill exists so the harness recognizes `/worlds` as a registered command; it does not reimplement the procedure.

Render the **Worlds** table from `system/WORLDS_AND_CAMPAIGNS.md` — every row, unfiltered, rendered from the file rather than recalled or supplemented from example paths named in other documents. Out-of-character; causes no state change; available with or without a loaded campaign.
