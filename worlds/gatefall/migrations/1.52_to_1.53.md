## What 1.53 changed

**A-Rank was deferred for a reason that did not survive being examined.** Through 1.52, Section 7.3 withheld both A-Rank and S-Rank on a single argument: every named S-Rank hunter in canon — Tereza Blažková's **Vltava**, Reid Calloway's **Overrun**, Dominic Crane's **Meridian** — carries one unique, singular *signature* technique rather than a templated continuation of a starter skill's ladder, so authoring an A- or S-Rank rung by the same pattern used for D/C/B risked contradicting established fact.

**The argument conflated two things this profile deliberately keeps apart.**

- A **signature** is innate, one per awakening, fixed for life, and authored per NPC in the character's own ledger entry under Section 13.6. That section grants one to **every named NPC hunter of D-Rank or above** — not only to S-Ranks. **Naomi Okafor is C-Rank and carries Still Room.**
- A **ladder rung** is what a *learned* technique gains from Rank. Section 13.6 states it in its own words: runes and skill books "add **learned** techniques on top" of a signature.

The two are different categories that already coexist at every Rank from D upward, **C-Rank included** — where this profile has authored ladder rungs since 1.6 and no one has ever suggested they contradict Naomi's signature. Authoring an A-Rank rung for a learned skill says nothing whatever about what any S-Rank's signature is.

**A-Rank is authored in all three tables**, on the same terms as every rung below it — a category and nothing else:

| Skill | A-Rank rung |
|---|---|
| **Keen Sense** | **Provenance** — the recent past of what he detects reads as clearly as its present |
| **Silent Step** | **Unattributed** — being seen no longer means being identified |
| **Exploit Pattern** | **Anticipatory** — a Pattern reaches what the subject has not yet done |
| **Field Command** | **Standing order** — a relayed Pattern persists for its recipients without him |
| **Resonance Extraction** | **Latent siting** — reads deposits that have not surfaced |
| **Sprint** | **Unbroken** — the effect no longer ends at an obstacle, a fall, or a change of medium |
| **Flash Step** | **Blind step** — the held-read requirement falls away |
| **Dagger Mastery** | **Unbroken edge** — the blade cannot be taken from him or destroyed by a resolved action |
| **Stone Skin** | **Against the unphysical** — the reduction answers non-physical harm as well |
| **Bulwark** | **Covering the line** — the reduction extends to every ally within reach |
| **Twin Fang** | **Answer** — the technique may be spent as a reaction |
| **Broken Rhythm** | **Broken formation** — he breaks a coordinated group's cadence as one |
| **Rupture · Mend · Mana Bolt** | *Magnitude only, by design* — the Rank baseline already multiplies at 1.56× |
| **Dimensional Projection** | Deferred to its own ratification, unchanged |

**No rung adds a modifier step** (Section 4.3's +1 cap is untouched), **none changes a Mana cost** (mastery's axis alone), and none adds magnitude the skill did not already have.

**S-Rank stays deferred, on a reason that survives the correction.** Not signatures — that is answered above. It is that S-Rank is the top of the ladder, where a *learned* technique would stand level with the six named singular gifts the world's entire hunter politics is built on. Whether a starting skill reaches that at all is a question about the world's power ceiling, not about a category ladder, and it is left to an owner ruling under Section 20.3. S-Rank is unreachable until System Rank A, which is level 40.

**Ladder columns become absolute Ranks.** All three tables now head their columns `E / D / C / B / A` instead of *First / Second / Third Rank above native*. The old indexing put Sprint's A-Rank rung (native E, fourth step) and Flash Step's A-Rank rung (native D, third step) in **different columns**, which is what made the deferred rung read as a property of the column rather than of the Rank. A native-D skill has no grant in the D column and the cell now says so.

**The repository ceiling guard parses the authored extent instead of storing it.** `validate_repository.ps1` carried the ceiling as a hand-maintained literal — `"C"` until 1.51, `"B"` until 1.53 — checked only against a contract test derived from the same literal, so the guard and its test could agree with each other while both disagreed with the profile. That is `F-013` exactly, and `F-013` recorded closing it as still-open work. Both sides now read the highest Rank appearing as a column header across these tables. **The absolute-Rank columns are what made this possible**; the old offset headings carried no Rank to parse.

## Migration procedure

**1.52 → 1.53 compatibility treatment.** Preserve every stored value and all resolved canon. Adoption recomputes nothing and rewrites nothing.

**1. Advance `profile_version` to `"1.53"`.** That is the only stored value this edge touches.

**2. Nothing is granted, because nothing is in reach.** Section 7.2 grants an authored category for each Rank a skill stands **above its native Rank**, and no skill in any Gatefall campaign stands at A-Rank. The highest is Keen Sense at B-Rank, one rung below. Unlike the 1.51 → 1.52 edge — where Dagger Mastery took two categories its held C-Rank already covered — **this edge pays no deferral**, because none had accrued.

**3. Nothing becomes ascension-ready that was not already.** Section 7.5's ceiling is System Rank + 1, and a Bearer at System Rank C is capped at B-Rank regardless of what A-Rank authors. A-Rank first becomes reachable at **System Rank B, level 30**. Run the standing readiness check at the next barrier as always; its answer is unchanged by this adoption.

**4. Nothing retroactive.** No past exchange is re-resolved and no rung applies backward. The new rungs apply from adoption forward, per Rules Section 13.2.

**5. Nothing else moves.** No pool, Stat, maximum, XP, level, System Rank, mastery level, use count, qualifying-scene count, `scope_floor`, title, item, equipment, gold, cash, deadline, streak, quest, or objective is touched. No skill's rendered effect changes, because no skill occupies a rung this edge authored.

Record adoption as a campaign Event at the adopting campaign's current anchor; consume no fictional time and reopen nothing. Immutable Profile 1.52-and-earlier checkpoints remain byte-unchanged and run the compatibility chain through 1.53 at readiness.
