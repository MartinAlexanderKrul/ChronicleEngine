## What 1.114 changes

**Section 7.4's Twin Fang follow-up multiplier grid gains an S-Rank row, and nothing else changes anywhere.**

The grid ran E through **A** and ended at `A / Master = x3.00`. Twin Fang has been **`[S-Rank] Master`** on the live campaign sheet since before this edge, so the multiplier the skill actually applies was not readable from the profile at all — the only place it could be found was the authoring rule in Section 7.3 (*"+0.35 to its follow-up multiplier per Rank"*) plus the grid's own internal `+0.15` mastery step, re-derived by hand at the table each time.

| Rank | Novice | Practiced | Adept | Expert | Master |
|---|---:|---:|---:|---:|---:|
| **S** *(new)* | x2.75 | x2.90 | x3.05 | x3.20 | **x3.35** |

**The row is the arithmetic continuation, and that was the ruling.** `F-069` asked explicitly whether S continues the pattern or is authored differently, on the precedent of `F-054`, where a Stat ladder added a rung that repeated the one below it instead of continuing. The owner ruled continuation: S Novice is A Novice `+0.35`, and each mastery step adds `+0.15`, exactly as every other row is built.

**No magnitude anywhere else moves.** No Rank baseline, no chassis multiplier, no weapon power, no other skill's grid, and no damage formula changes. Twin Fang's Mana cost, mastery level, use counters and terminal status are untouched.

## What did not change

**This edge is a table completion, not a rebalance.** The value it publishes is the value the skill has already been applying — Section 7.3's per-Rank rule has authored it since 1.54, and the grid simply stopped short of printing it. A campaign that has been resolving Twin Fang at `x3.35` was resolving it correctly and needs no re-settlement; one that has been resolving it at `x3.00` was reading a row that does not describe its skill.

**No promoted Event is re-scored**, on Section 9.5's standing precedent for a rule that governs forward. Any resolved Twin Fang strike keeps the figure its own Event recorded.

**`skills_known` is not rewritten by this edge.** The live sheet's Twin Fang entry does gain its multiplier sentence back in the same change, but that is a **render repair** rather than a migration step: the sentence was lost when the entry was rewritten at mastery-terminal (`F-069`'s second half), and restoring a canonical magnitude that a rewrite deleted is not a state transform.

## Migration procedure

This edge **transforms no stored state.**

**1. Advance `profile_version` to 1.114** on the campaign's live character sheet, and re-pin `world_rule_profile:` in `090_CAMPAIGN_STARTUP.md`. This is the only touched state path.

**2. No skill is re-derived, re-Ranked or re-mastered.** Twin Fang's own entry is unchanged in Rank, cost, mastery, counters and acquisition route.

**3. A capture restored across this edge runs step 1 only.** If its Twin Fang sits below S-Rank, the new row is inert for it and the grid it already read is unchanged.

**Immutable checkpoints are byte-unchanged.**
