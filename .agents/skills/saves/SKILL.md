# /saves — List Checkpoints

Thin dispatcher only — this skill exists so the harness recognizes `/saves` (and its alias `/checkpoints`) as a registered command; it does not reimplement the procedure.

List the current campaign's checkpoints under `saves/` with their labels and creation times (and, if the campaign keeps one, its `saves/README.md` save index — read and honor it per Destructive-Command Guards, e.g. Reikon's superseded-original note). Out-of-character; causes no state change. Requires a loaded campaign.
